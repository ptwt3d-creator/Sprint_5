# Sprint 5

## Описание тестов

- `test_exit_button_from_personal_account_page` - Выход из профиля через личный кабинет.

- `test_login` - Проверка Входа через Кнопки на формах: Восстановления пароля, регистрации, личный кабинет. И после перехода по кнопке 'Войти в аккаунт' на главной странице.

- `test_have_message_error_for_invalid_password` - Проверка наличия сообщения о не допустимом пароле.

- `test_constructor_tabs` - Проверка перехода между секциями Булки, Соусы, Начинки в Конструкторе.

- `test_open_constructor_from_personal_account_page` - Проверка открытия конструктора из личного кабинета через Логотип Stellar Burgers.

- `test_open_personal_account_from_main_page` - Проверка открытия Личного кабинета с главной страницы.

- `test_registration` - Проверка регистрации(Без входа).
